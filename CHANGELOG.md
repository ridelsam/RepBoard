# Changelog

All notable public changes to RepBoard will be documented here.

## [1.4.0] - 2026-08-07

### Initial public release

- Added touch-first completed-set tracking.
- Added independent set goals for every exercise.
- Added editable, removable, and reorderable exercises.
- Added workout Start, Pause, Resume, Finish, Restart, and Reset controls.
- Added workout history with finished times.
- Added persistent touch/stylus whiteboard tools.
- Added keep-awake, always-on-top, and fullscreen controls.
- Added Windows installer and portable builds.

Versions before 1.4.0 were private development iterations and were never publicly released. They wandered so this release could run.
